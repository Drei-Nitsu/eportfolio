## 📂 Featured Capstone & Academic Projects

### 1. 🍗 Fedelicious Wings Restaurant Point-of-Sale (POS)
> **Stack:** Node.js, Express.js, MySQL, Tailwind CSS &bull; *Web POS Prototype*

* **Overview:** A web-based dining POS built to eliminate manual billing and ordering errors for quick-service food operations.
* **QA & Testing Highlights:**
  * **Boundary Value Analysis (BVA):** Isolated an arithmetic flaw where negative discount inputs (`-10%`, `-₱100`) caused total invoices to increase, corrupting sales ledgers. Enforced strict validation (`0% &le; discount &le; 100%`).
  * **Database Transaction Rollbacks:** Ran SQL verification queries in MySQL to ensure cancelled orders safely rolled back stock deductions in the `inventory_items` table.
  * **Workflow Verification:** Validated order statuses across the table lifecycle from draft to receipt invoice printing.
